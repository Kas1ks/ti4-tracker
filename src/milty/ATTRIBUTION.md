# Milty Draft attribution

Slice-generation rules and tile/faction reference data are inspired by
[shenanigans-be/miltydraft](https://github.com/shenanigans-be/miltydraft)
(expanded miltydraft.com). Logic was reimplemented in JavaScript for TI4 Tracker;
seeds are **not** compatible with the PHP `mt_rand` generator.

Twilight Imperium and related marks are property of Fantasy Flight Games /
Asmodee. This project is unofficial and not affiliated.
